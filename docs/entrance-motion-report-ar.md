# تنفيذ دخول العناصر — الإصدار الرابع

التاريخ: 28 أكتوبر 2026. المرجع: IMG_5687.MP4 والتحليل الزمني المرفق بالمحادثة.

## النتيجة والنطاق

طُبّق إيقاع الدخول المتداخل على مشروع Ahmed Khaled الحقيقي في نسخة العمل المختارة سابقًا. الهيرو لم يعد يظهر ككتلة نصية واحدة؛ لكل عنصر دخوله. الشريط له موجته المستقلة، والفولدرات والأدوات تدخل بالتتابع عند وصول صفها إلى الشاشة. فقرة التعريف تتكشف كلمة بعد كلمة، والخدمات تبدأ بأيقوناتها ثم النصوص. بقية كتل الموقع وعناوين الأقسام تستخدم نفس منحنى الدخول الهادئ مع التمرير.

المحتوى والتخطيط الحاليان مختلفان عن موقع المرجع. هذا تنفيذ لسلوك الدخول على محتوى أحمد خالد، وليس إنشاء مشاهد WAHBA أو نسخ الجمل والرموز والتحولات القصصية الخاصة بصاحب المرجع. الهيرو الحالي بلا صورة شخصية أصلًا؛ لم تُضف صورة بديلة أو يُستبدل تصميمه.

شكل الفولدر المغلق وصورة المشروع الظاهرة فيه وحركة فتح الواجهة من أسفل محفوظة من الإصدار الثالث. لم يتغير ملف CSS الخاص بهندسة الفولدر. حركة الدخول تستخدم خاصية translate المستقلة على الغلاف، بينما تستمر حركة الفتح والدوران على العناصر الداخلية؛ ولا تُضاف حالة is-open لمجرد دخول الصفحة.

## دليل المقارنة الزمني

أزمنة المرجع من بداية التسجيل، وتبدأ بعض حركاته قبل أول فريم. أزمنة التنفيذ أدناه **إعدادات في الكود** محسوبة من دخول المجموعة مجال الرؤية؛ ليست قياسًا لفيديو جديد صادر من متصفح. لم تُجر مطابقة فريمات فعلية بين فيديو المرجع وتسجيل جديد.

| العنصر | الملاحظة في المرجع | الإعداد في التنفيذ |
|---|---|---|
| الأدوات: وجه الصندوق | خافت من البداية؛ ثبات قرب 0.63–0.77ث | بداية المجموعة، مدة 0.70ث وصعود 22px |
| فولدر المشاريع | أول وضوح قرب 0.03–0.07ث؛ ثبات قرب 0.67–0.77ث | تأخير 0.05ث + مدة 0.70ث = نهاية 0.75ث |
| الفولدر الأوسط | بداية 0.23–0.27ث؛ ثبات 0.77–0.87ث | تأخير 0.20ث + مدة 0.70ث = نهاية 0.90ث |
| الفولدر الأيمن | بداية 0.37–0.40ث؛ ثبات قرب 1.00ث | تأخير 0.35ث + مدة 0.70ث = نهاية 1.05ث |
| مروحة الأدوات | تبدأ خافتة قرب 0.20ث وتكمل قرب 1.03ث | 7 طبقات، أولها 0.20ث، بفاصل 0.055ث، مدة كل طبقة 0.50ث؛ آخر نهاية 1.03ث |
| أيقونات الشريط | اكتمال متدرج من قرب الشعار إلى اليسار | العلامة أولًا، الروابط بفاصل 0.075ث ومدة 0.50ث؛ العدد والتصميم مختلفان عن المرجع |
| الهيرو | بداية الاسم والخلفية والصورة غير مسجلة | اقتراح ملائم للموقع: التعريف 0، الاسم 0.06، الدور 0.13، المقدمة 0.21، الأزرار 0.28/0.35/0.42ث |
| فقرة التعريف | كلمات تتضح تدريجيًا أثناء التمرير | كلمة كل 0.15ث، مدة 0.55ث لكل كلمة، وانتقال رأسي 10px؛ الطول مختلف عن جملة المرجع |
| الخدمات | الرموز تصل قبل العناوين والأوصاف | الأيقونة تبدأ، النص الرئيسي يتبعها بنحو 0.12ث، ثم الوسوم؛ تشغيل عند وصول البطاقة للشاشة |

صعود الفولدر في التنفيذ 24 CSS px، ومنحنى الحركة cubic-bezier(0.22,1,0.36,1). قياس المرجع البالغ نحو 14 بكسل تسجيل لا يُنقل حرفيًا إلى CSS لأن مقياس التسجيل الأصلي غير معلوم. لا توجد ضبابية دخول إضافية؛ الخامة الزجاجية الأصلية مستمرة.

العناصر تظهر مرة واحدة لكل تركيب للصفحة. ظهور الأقسام مرتبط بمجال الرؤية، ولا توجد مؤقتات 20 أو 25 أو 59 ثانية من بدء فتح الموقع. في الشاشات حتى 840px، كل فولدر مجموعة مستقلة، وتأخيره لا يتجاوز 0.12ث، حتى لا ينتظر بطاقة خارج الشاشة. تتابع طبقات الأدوات الداخلي يحتفظ بفواصله.

## التعامل مع التحميل وإمكانية الوصول

- تهيئة صغيرة في رأس الصفحة تمنع وميض المحتوى كاملًا قبل تجهيز حركاته. إذا لم تكتمل تهيئة الصفحة خلال ثانيتين، تُتاح العناصر تلقائيًا؛ وإذا وصلت التهيئة متأخرة، لا تعيد إخفاء المحتوى الظاهر.
- عند تعطيل JavaScript، تظل نسخة الخادم مرئية. وعند غياب IntersectionObserver، يتحول العرض إلى محتوى ثابت متاح.
- تفضيل تقليل الحركة يُظهر المحتوى مباشرة. تغيير التفضيل أثناء التشغيل يحرر العناصر المنتظرة أيضًا.
- وصول التركيز بلوحة المفاتيح أو الضغط أثناء الدخول يكشف المجموعة فورًا؛ لا ينتظر المستخدم نهاية الحركة لاستخدام الرابط أو الحقل.
- فقرة التعريف تحتفظ بجملة متصلة لقارئ الشاشة، والكلمات البصرية المتحركة مستثناة من شجرة القراءة لتجنب تكرارها.
- اكتمال الحركة يزيل حالتها المؤثرة في translate والشفافية، فلا يبقى سياق تكديس إضافي يعوق ارتفاع أوراق الفولدر أو أيقونات الأدوات.
- التبويبات التي تضيف محتوى جديدًا تُسجل عناصرها الجديدة للمشاهدة. العناصر المنفصلة تُزال مراقبتها ومؤقتاتها.

## التحقق المنفذ

| الفحص | النتيجة |
|---|---|
| npm run build | ناجح: العميل والخادم وإخراج Nitro |
| npx tsc --noEmit | ناجح بلا أخطاء |
| npm run lint | ناجح: صفر أخطاء، 10 تحذيرات Fast Refresh سابقة |
| اختبارات الفولدرات | 13/13 ناجحة في jsdom |
| اختبارات الدخول | 14/14 ناجحة في jsdom، مع محاكاة أحداث مجال الرؤية وتفضيلات الوسائط |
| استجابة المعاينة المحلية | HTTP 200، ثلاثة روابط مشاريع، عنوان رئيسي واحد، 128 عنصرًا مسجلًا للدخول |
| بيانات المشاريع والصور والملفات العامة | تطابق SHA-256 مع الحالة السابقة؛ التفاصيل في preservation.json |

اختبارات الفولدرات تشمل: بقاء أسماء المشاريع وروابطها وصورها، إظهار الصورة في الطبقة الأمامية، التركيز وEscape، اللمسة الأولى والثانية، التبديل بين المشاريع، الإغلاق من الخارج، اختيار الأدوات، العمل بلوحة المفاتيح بعد اللمس، واللغة الإنجليزية.

اختبارات الدخول تشمل: الانتظار خارج الشاشة، التداخل بين الفولدرات، عدم تكرار الدخول بعد اكتماله، إظهار المحتوى عند التركيز والضغط، تقليل الحركة من البداية وأثناء التشغيل، غياب IntersectionObserver، انتهاء مهلة التحميل، استقلال البطاقات على الموبايل، تغيير عرض الشاشة، محتوى التبويبات الجديد، العودة من تبويب بالخلفية، وتنظيف المراقبين.

عولجت أخطاء تنسيق سابقة في ملفي awards.tsx وstack.tsx حتى ينجح الفحص العام. المقارنة بعد التنسيق تؤكد أن تغيّرهما تنسيقي فقط، بلا تغيير سلوكي.

## القيود وحالة القبول

**مقبول من جهة البناء والأنواع والسلوك الذي تغطيه الاختبارات. المطابقة البصرية الدقيقة غير مثبتة بعد.** لم تتوفر أداة تحكم بالمتصفح خلال هذه الجولة؛ لذلك لا توجد دعوى بمشاهدة الحركة الجديدة أو تسجيلها أو قياس معدل الإطارات أو اختبار لمس على جهاز فعلي. استجابة HTTP وjsdom لا تثبت نعومة الرسم أو تطابقه بكسلًا ببكسل.

تظل مكتبة المرجع وإعداداته الأصلية وبداية ظهور الاسم والصورة قبل أول فريم غير معلومة. القيم المختارة لإعادة الإيقاع موضحة أعلاه كإعدادات تنفيذ، لا كقيم مستخرجة يقينًا من المصدر.

## المعاينة والمراجعة

افتح http://127.0.0.1:5173/?entrance=v4 من بداية الصفحة دون #projects، ثم حدّثها لمشاهدة دخول الهيرو والشريط. مرّر إلى المشاريع لرؤية موجة الفولدرات والأدوات. جرّب الفتح بالماوس، ثم Tab وEscape، ثم تقليل الحركة من إعدادات النظام. على الموبايل، راقب دخول كل بطاقة عند وصولها للشاشة، واللمستين لفتح المشروع.

لتشغيل النسخة خارج هذه الجلسة: npm ci ثم npm run dev. الحزمة تحتوي المشروع المعدل والملفات العامة ووثائق التحقق، وتستثني node_modules وملفات البناء المؤقتة.
