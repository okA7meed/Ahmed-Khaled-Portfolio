## التحقق الفعلي

- `npm run build`: ناجح، إخراج العميل والخادم وNitro في `.output/`؛ التفاصيل في `build.log`.
- `tsc --noEmit`: ناجح بلا أخطاء.
- `npm run dev -- --host 127.0.0.1 --port 5173`: تم تشغيله، واستجابة الصفحة HTTP 200.
- 22/22 اختبار متصفح Chromium ناجحة؛ التفاصيل في `acceptance.json`.
- قياس أحداث animationstart وanimationend أثبت أن الإطار يستقر قبل ظهور الشعار، وأن محتوى الهيرو يتبع آخر زر في الشريط، وأن التوقيع يبدأ بعد استقرار البورتريه. الأحداث الفعلية محفوظة في `opening-events.json`.
- لا تجاوز في عرض الصفحة أو العنوان أو الشريط في 20 حالة: العربية والإنجليزية × 320، 375، 390، 700، 768، 851، 900، 1024، 1280، 1672 بكسل. القياسات بعد استقرار التخطيط محفوظة في `responsive.json`.
- تم اختبار الثيم الفاتح والداكن وحفظ الثيم بعد التحديث، وقائمة الموبايل والانتقال للأقسام، وملف السيرة PDF، وتقليل الحركة من بداية التحميل وأثناءها، والنسخة بلا JavaScript.
- لم تسجل أخطاء تشغيل في المتصفح. راجعت اللقطات النهائية ومراحل الافتتاح بصريًا؛ لا تُعد هذه مطابقة بكسلية لكل تفاصيل الصورة المرجعية أو اختبارًا على هاتف فعلي.

## الملفات والتشغيل

الملفات السابقة المعدلة محفوظة في `original/`، وبصماتها قبل/بعد التعديل في `changed-files.json`. الملفات الجديدة للتنفيذ هي `src/config/opening.ts` و`src/components/hero-signature.tsx` والصورة الشفافة.

للتشغيل من مجلد المشروع:

```sh
npm run dev
```

ولتجهيز المشروع على جهاز جديد:

```sh
npm ci
npm run build
npm run dev
```

يمكن إعادة اختبار المتصفح بواسطة `browser-check.mjs` إذا كانت مكتبة Playwright ومتصفح Chromium متاحين في بيئة الاختبار. استُخدمت مكتبة محلية متاحة دون إضافة اعتماد للمشروع. يقرأ الاختبار المسار الاختياري من `PLAYWRIGHT_MODULE` ورابط المعاينة من `PORTFOLIO_QA_URL` ومجلد النتائج من `PORTFOLIO_QA_OUT`.
