# محفظة أحمد خالد حسين

نسخة ثنائية اللغة من الموقع الشخصي، مبنية على React 19 وTanStack Start وVite. تحافظ على بيانات المشاريع والسيرة والشهادات والتواصل الموجودة في المصدر، وتستخدم تخطيطًا تحريريًا دافئًا ومجلدات مشاريع تفاعلية.

## التشغيل

```sh
npm ci
npm run dev
```

## اللغة والخط

يظهر الموقع بالعربية افتراضيًا. يمكن التبديل إلى الإنجليزية من شريط التنقل، ويُحفظ الاختيار على الجهاز. يستخدم الموقع الخط الرسمي ثمانية من مصدره المنشور دون نسخ ملفات WOFF2 أو إعادة توزيعها؛ راجع `docs/font-usage.md` لمصدر الخط والترخيص.

## صورة البورتريه الاختيارية

لا تحتوي واجهة البداية على صورة شخصية. لم تُضف صورة بورتريه لعدم وجود أصل شخصي مناسب ضمن الملفات. إذا أضيفت صورة حقيقية لاحقًا، استخدم مسار الإعداد الوحيد في `src/config/portrait.ts` وضع ملف الصورة تحت `public/images/`، ثم أعد استخدام ذلك الإعداد في القسم المقصود فقط.

## التحقق

الأوامر المتاحة في المشروع: `npm run build` و`npm run lint`. يمكن تشغيل فحص TypeScript بواسطة `npx tsc --noEmit`.

## النشر على Vercel

هذه النسخة محفوظة في مشروع WebDev، ولم يتغير عنوان Vercel المنشور. إعداد Nitro الحالي يبني لهدف `cloudflare-module`؛ يلزم ربط المستودع والتحقق من هدف نشر Vercel قبل استبدال النسخة الحية. لا تفترض أن ملف ZIP وحده حدّث الموقع المنشور.
