# ملاحظات مطابقة مرجع المجلدات

## الملفات المرجعية

- الفيديو الأحدث من المستخدم: `publer-1792870190259(1).mov`، مقطع عريض 1024×160 يقارب 10 ثوانٍ و30 إطارًا/ثانية؛ لم يصاحبه ملف صورة منفصل جديد.
- مرجع الشكل الثابت من حزمة إعادة التصميم: `03_SECTION_MOCKUPS/02_projects_folder_cards.png` و`03_SECTION_MOCKUPS/03_tools_and_technologies_folder.png`.
- توجيه الحزمة `FOLDER_HOVER_MATCH_PROMPT.md`: الفيديو مرجع الحركة والصور مرجع الشكل. عند اختلاف لون مجلد الأدوات بين الفيديو الداكن والصورة الفاتحة، استُخدمت الواجهة الكريمية الظاهرة في الصورة الثابتة، مع إبقاء الحركة مستندة إلى الفيديو.

## ما يظهر في الفيديو

- مجلدات المشاريع تعرض أغلفة المشاريع الفعلية، وترتفع من خلفها أوراق منفصلة على مستويات متتابعة، ثم تعود عند مغادرة العنصر. لا توجد بيانات مصدر تثبت منحنى CSS أو زمنًا أصليًا دقيقًا.
- مجلد الأدوات مستقل عن مجلدات المشاريع. شعارات العلامات الملونة متراكبة؛ الأيقونة المعنية تتقدم بصريًا وترتفع وتكبر مقارنة ببقية المجموعة. لا أضيف دورانًا أو ارتدادًا غير محسوم.
- الألسنة متصلة بصريًا بجسم المجلد، وتفصل الظلال الناعمة بين الوجه والأوراق. تفاصيل القياسات الدقيقة تُضبط بصريًا من الصور لا من بيانات الفيديو.

## تطبيق التفاعل في المصدر

- يحتفظ كل مشروع بصورة غلافه ورابطه ووصفه وتقنياته الفعلية. للمشروعين الأول والثالث ثلاث أوراق خلفية، وللمشروع الثاني ورقتان؛ تحمل الأوراق أسماء أو تقنيات مأخوذة من بيانات المشروع نفسه.
- على hover أو focus يرتفع مستوى الورقة الأولى قرابة 20px، والثانية 33px، والثالثة 47px، مع تفاوت بسيط في الإزاحة الأفقية. تعود الإزاحات عند مغادرة العنصر أو فقدان التركيز، ولا يحدث دوران.
- يعرض مجلد الأدوات التقنيات الحقيقية المسجلة في المصدر فقط. الشعارات طبقة مرئية زخرفية؛ يفعّل hover أو النقر على اسم التقنية الأيقونة المرتبطة بها، بحيث ترتفع وتكبر إلى 1.4× وتتقدم أمام بقية المجموعة. النقر يدعم اللمس، وتبقى أسماء التقنيات متاحة للوحة المفاتيح.
- يؤكد اختبار المتصفح أن اختيار Next.js فعّل أيقونة واحدة فقط، وأن رابط المشروع يرتفع بالتركيز إلى طبقات منفصلة ثم يعود عند إزالة التركيز. يحترم CSS إعداد `prefers-reduced-motion`.
- قيم CSS الحالية: انتقال الأوراق 360ms خطيًّا، وانتقال الأيقونة 360ms بمنحنى `cubic-bezier(0.2, 0.8, 0.2, 1)`؛ هذه قيم تنفيذية اختيرت بالمراجعة، وليست قياسات مستعادة من الملف المرجعي.

## حدود المطابقة

المطابقة بصرية وسلوكية مع الحالات المرئية في المرجع، وليست استعادة حرفية للشفرة أو للـkeyframes الأصلية؛ فالفيديو والصور لا يكشفان بيانات CSS الأصلية أو توقيت كل انتقال بدقة. لم تُضف حركات دوران أو ارتداد غير مؤكدة، ولم تُستبدل الأغلفة بمكوّنات بطاقات عامة.
