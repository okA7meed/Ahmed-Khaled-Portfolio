# النسخة المطوّرة — Midnight Portfolio

هذه النسخة مبنية على مشروع React + Vite + TanStack الأصلي، وليست معاينة HTML منفصلة.

## التعديلات المنفذة

- تم تعديل الهيرو إلى تصميم داكن، مع اسم كبير ونصوص على اليمين وخط أفق مضيء على اليسار؛ لا توجد صورة شخص.
- تصميم مكوّن المشاريع مجددًا على هيئة ثلاثة فولدرات بيضاء قصيرة في صف، بجوار فولدر أدوات أسود، مع خلفية وظلال وعلامات فولدر حقيقية.
- الأوراق داخل الفولدرات مستقلة عن الواجهة الأمامية، تخرج بشكل متتابع عبر hover/focus وتعود عند الخروج. تظل روابط المشاريع الأصلية موجودة.
- مجلد الأدوات يضم أيقونات التقنيات، وتبرز الأيقونة المختارة أمام باقي الأيقونات.
- على شاشات اللمس: اللمسة الأولى تفتح الفولدر بصريًا، والثانية تفتح الرابط.
- إعادة تنسيق أقسام الخدمات والمهارات والشهادات والتواصل والنماذج والتاريخ والخبرة في النسق الداكن نفسه.
- الحفاظ على المحتوى العربي والإنجليزي، صور الشهادات، روابط المشاريع، روابط التواصل، نموذج WhatsApp، وملف السيرة الذاتية.
- الشهادات تتنقل في شريط أفقي مع أزرار؛ ومعرض العرض المكبر الأصلي ما زال موجودًا.

## طريقة التشغيل

تأكد من وجود Node.js 22 أو أحدث. افتح Terminal من داخل مجلد `ahmed-khaled-portfolio` ثم:

```bash
npm install
npm run dev
```

افتح الرابط الذي يعرضه Vite في Terminal، وغالبًا يبدأ من `http://localhost:5173`.

**تحذير:** لم يكن تثبيت npm packages أو تشغيل المتصفح متاحًا في بيئة تعديل الملفات بسبب غياب الاتصال بمستودع npm. تم فحص ملفات TSX المعدّلة بفاحص TypeScript وفحص ملفات CSS بنجاح، لكن لم يتم تأكيد build كامل أو اختبار التشغيل الفعلي على المتصفح. نفذ `npm run build` وراجع الواجهة بصريًا على جهازك قبل النشر.
