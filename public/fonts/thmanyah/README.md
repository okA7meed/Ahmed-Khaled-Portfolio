# Thmanyah

Original **thmanyah serif display** webfonts, in weights 300, 400, 500, 700 and 900.
These are the same files previously referenced remotely in the portfolio's CSS,
now served locally under the single CSS family name `Thmanyah`.

The font's built-in `ss01` feature enables its extended Arabic stylistic forms.
No elongation characters are inserted into the content, and the font files have
not been modified. Copyright and naming metadata remain embedded in each file.

Official font information: https://font.thmanyah.com/
