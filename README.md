## Contact form → WhatsApp (click-to-chat)

The contact form in the `#contact` section opens a pre-filled WhatsApp chat
using a **WhatsApp click-to-chat link** (`wa.me`) — no backend, no API
credentials, and no automatic sending.

- When the visitor fills in their name, email and project details and clicks
  **Send message**, the form validates the fields and builds a professionally
  formatted message.
- The message is URL-encoded and the visitor is taken straight to the owner's
  WhatsApp chat at `+20 1206411015` with the message already written.
- The visitor presses **Send** manually — nothing is sent automatically.

No environment variables or server configuration are required.
