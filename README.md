## ✨ مميزات الموقع

صُمم الموقع لتقديم تجربة شخصية متكاملة تتجاوز الشكل التقليدي لمواقع Portfolio.

- **تصميم تفاعلي:** واجهات حديثة، انتقالات سلسة، وتفاصيل بصرية مدروسة.

- **دعم لغتين:** العربية والإنجليزية مع اتجاهات عرض مناسبة لكل لغة.
- **الوضع الداكن والفاتح:** تجربة متكيفة مع تفضيلات المستخدم.
- **معرض مشاريع تفاعلي:** استعراض الأعمال من خلال مجلدات وبطاقات قابلة للتفاعل.
- **تصميم متجاوب:** تجربة مهيأة لأجهزة الكمبيوتر والتابلت والهواتف.
- **إمكانية الوصول:** دعم تقليل الحركة والتنقل الواضح بين أقسام الموقع.

## 💻 تشغيل المشروع محليًا

يتطلب المشروع تثبيت Node.js وnpm.

تحميل المستودع:

```bash
git clone https://github.com/okA7meed/Ahmed-Khaled-Portfolio.git
```

الدخول إلى مجلد المشروع:

```bash
cd Ahmed-Khaled-Portfolio
```

تثبيت الاعتماديات:

```bash
npm ci
```

تشغيل بيئة التطوير:

```bash
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
```

ولفحص جودة الكود:

```bash
npm run lint
```
