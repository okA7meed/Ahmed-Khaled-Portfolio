# محفظة أحمد خالد حسين

نسخة ثنائية اللغة من الموقع الشخصي، مبنية على React 19 وTanStack Start وVite. تحافظ على بيانات المشاريع والسيرة والشهادات والتواصل الموجودة في المصدر، وتستخدم هيرو ببورتريه دائري ومدارات موكّا وتوقيع SVG متدرج ومجلدات مشاريع تفاعلية.

## التشغيل

```sh
npm ci
npm run dev
```

## اللغة والخط

يظهر الموقع بالعربية افتراضيًا. يمكن التبديل إلى الإنجليزية من شريط التنقل، ويُحفظ الاختيار على الجهاز. يستخدم الموقع ملفات خط ثمانية المحلية الموجودة في `public/fonts/thmanyah/`، مع خصائص OpenType للحروف العربية المرسلة. راجع مستندات الخط الموجودة في `docs/`.

## الهيرو وتسلسل الافتتاح

البورتريه الحالي مأخوذ من الصورة الجديدة التي أرسلها أحمد، والنسخة الشفافة المستخدمة في الهيرو في `public/images/ahmed-khaled-cutout-v2.png`. مسار الصورة مركزي في `src/config/portrait.ts`، مع الاحتفاظ بالصور السابقة.

توقيت ظهور الإطار والشعار والروابط ثم محتوى الهيرو والصورة والتوقيع مضبوط في `src/config/opening.ts`. التوقيع مسارات SVG حقيقية في `src/components/hero-signature.tsx`. يعمل التصميم على الهاتف وباللغتين والوضعين الداكن والفاتح؛ تفضيل تقليل الحركة يعرض المحتوى فورًا.

الكرات ولمعة المدار حول الصورة تتحرك باستمرار حركة هادئة، وتتوقف مع إعداد تقليل الحركة. يظهر الناف بار أسرع بحوالي 20% مع الحفاظ على ترتيب عناصره.

تُعطّل قائمة الحفظ والسحب على الصور، وتبقى الروابط ومعاينات الشهادات والضغط العادي متاحة. هذا تقليل للحفظ المباشر؛ الصور المعروضة على الويب لا يمكن منع نسخها نهائيًا.

نتائج التحديث الأخير ولقطاته ونسخه الاحتياطية في `docs/hero-motion-update-qa/`. تقرير التصميم والافتتاح السابق في `docs/hero-opening-qa/`.

## التحقق

الأوامر المتاحة في المشروع: `npm run build` و`npm run lint`. يمكن تشغيل فحص TypeScript بواسطة `npx tsc --noEmit`.

## النشر على Vercel

هذه النسخة محفوظة في مشروع WebDev، ولم يتغير عنوان Vercel المنشور. إعداد Nitro الحالي يبني لهدف `cloudflare-module`؛ يلزم ربط المستودع والتحقق من هدف نشر Vercel قبل استبدال النسخة الحية. لا تفترض أن ملف ZIP وحده حدّث الموقع المنشور.
